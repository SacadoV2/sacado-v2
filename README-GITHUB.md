# SACADO V2 — page Lycée-UP

Site statique, prêt pour GitHub Pages, avec images stockées localement.

## Images
- Capture authentique du tableau de bord de Sacado V2.
- Captures authentiques d’exercices : coccinelle (primaire/tablette), Thalès (collège/ordinateur), variations (lycée/téléphone).
- Véritables couvertures des Cahiers-manuels Génération 5 fournies par l’équipe.
- Logos des cinq établissements à l’étranger issus des captures fournies.

## Publier
1. Décompresser le ZIP.
2. Mettre **tout le contenu du dossier**, y compris `assets`, à la racine d’un dépôt GitHub public.
3. Settings > Pages > Deploy from a branch > main > /(root).
4. Le domaine `sacado-v2.fr` est inscrit dans `CNAME`, mais doit être acquis et configuré auprès d’un fournisseur DNS avant qu’il fonctionne.
5. Vérifier les autorisations de reproduction des logos et les formulations GAR/RGPD avant diffusion.

Pour un aperçu local, ouvrir `index.html` dans un navigateur.
